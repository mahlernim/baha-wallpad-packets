상위 문서: [README](../README.md)

공개 출처와 과거 실측 기록을 모았다. 현재 해석은 `docs/`에, 그 근거와 조사 과정은 이곳에 정리한다.

## 자료 목록

- [sources.md](sources.md): 출처별 제목, 발행 주체, 적용 범위, 확인일, 링크
- [search-coverage.md](search-coverage.md): 검색어, 조사 범위, 접근하지 못한 자료와 한계
- [raw-session-notes.md](raw-session-notes.md): 전체 조사 로그, 테스트 이력, 패킷 해석 과정
- [heater-packets.html](heater-packets.html): 분석 과정에서 만든 난방 HTML 참고 문서

## 읽는 순서

먼저 [지식 지도](../docs/knowledge-map.md)에서 주제별 문서를 읽고, 근거가 필요하면 출처 원문이나 실측 기록을 확인한다.

`raw-session-notes.md`와 `heater-packets.html`에는 실패한 가설과 중간 해석도 남아 있다. 현재 해석과 차이가 있으면 `docs/`를 기준으로 읽는다. 새 자료는 [기여 안내](../CONTRIBUTING.md)에 따라 요약과 링크로 추가한다.
