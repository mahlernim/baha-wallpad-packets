# 지식 지도

[README](../README.md) | [공개 출처](../reference/sources.md) | [미확인 사항](open-questions.md)

모델 확인부터 패킷 해석, 구현 검토까지 필요한 문서를 연결한다. 브랜드와 외관이 비슷해도 모델별 차이를 먼저 확인한다.

## 주제별 안내

| 찾으려는 정보 | 문서 | 근거의 중심 |
| --- | --- | --- |
| 내 월패드가 어느 계열인가 | [모델과 계보](model-family.md), [하드웨어](hardware.md) | 제품 라벨, KIDP / iF 기록 |
| BAHA / YPP / VRID는 어떤 관계인가 | [모델과 계보](model-family.md) | 당시 기업 발표 |
| 패킷을 어디서 나누고 어떻게 검증하는가 | [프로토콜 개요](protocol-overview.md) | 실측 프레임, 길이 / XOR 일치 |
| 4채널 / 6채널 조명을 어떻게 구분하는가 | [조명](lighting-node-10-04.md) | 실측과 외부 제보를 구분한 표 |

| MC200 / FCU / 온도조절기는 어떻게 연결되는가 | [난방 시스템](heating-system.md) | 모델별 설명서; BAHA 연결은 별도 추론 |

| USB 드라이버 / RS485 전기 규격은 어디서 찾는가 | [하드웨어](hardware.md) | Silicon Labs / TI 공식 자료 |
| 아직 없는 주소표 / 설명서는 무엇인가 | [미확인 사항](open-questions.md) | 검색 범위와 필요한 추가 근거 |

## 근거의 종류

| 표시 | 뜻 | 그것만으로 확정할 수 없는 것 |
| --- | --- | --- |
| **실측** | 이 저장소의 장비에서 캡처하거나 상태 변화를 확인 | 다른 모델 / 설치의 동일 동작 |
| **외부 제보** | 다른 작성자가 자신의 자료로 공개 | 독립 재현, 누락된 응답 / 배선 / 펌웨어 |
| **제품 자료** | 제조사 설명서, 제품 등록, 직접 발행한 발표 | 특정 BAHA 패킷과의 연결, 현재 설치 기능 |
| **구현 관찰** | 링크한 커밋에서 코드가 수행하는 동작 | 실제 장비 성공, 현재 배포된 펌웨어 상태 |
| **계산 / 추론** | 체크섬 계산, 프레임 비교, 근거를 연결한 해석 | 물리적 제어 성공이나 미확인 프로토콜 규격 |
| **미확인** | 필요한 원문 / 캡처를 확보하지 못함 | 자료가 세상에 없다는 결론 |

자료가 충돌하면 모델·날짜·펌웨어·통신 구간을 비교한다. UI 표현과 실제 명령이 다른 경우도 있으므로, 서로 다른 결과의 조건과 근거를 함께 남긴다.

## 검색어와 용어

| 검색어 | 연결할 정보 / 주의 |
| --- | --- |
| `BAHA`, `바하`, `삼성바하`, `BaHa-Cube`, `BHWP` | 삼성중공업 제품 기록. `BHWP`만 검색하면 무관한 약어가 많이 나온다. |
| `Samsung Heavy Industries`, `삼성중공업 수원 디지털사업부` | 제조사 / 디자이너 기록 |
| `YPP`, `VRID`, `브리드` | 후속 사업의 역사. 현행 앱 지원을 뜻하지 않는다. |
| `Samsung SDS`, `EZON`, `SHT`, `SHN`, `직방` | 인접 검색 계열. BAHA와 호환된다는 뜻이 아니다. |
| `Honeywell`, `Resideo`, `MC200`, `MC200F`, `DT300F-S`, `LT200` | 난방 제품군. 모델 접미사와 문서 개정을 확인한다. |
| `PLC` | 인용한 난방 문서에서는 전력선 통신. 일반 산업 문맥의 제어기 약어와 구분한다. |
| `FCU` | 인용한 모델의 시스템 연결 대상 표기. 명칭만으로 BAHA 노드 번호를 부여하지 않는다. |
| `capability`, `channel_count`, `mask` | `04` 채널 수와 `0F` 비트마스크를 구분한다. |

## 검색 방법

GitHub에서는 모델명, `40 90`, `외출`, `PLC`처럼 구체적인 단어로 검색한다. 패킷은 읽기 쉽도록 바이트 사이를 띄어 쓴다. 예를 들어 `02100602023F3F1400`은 `02 10 06 02 02 3F 3F 14 00`이다.

로컬 검색 예:

```sh
rg -n 'MC200|외출|PLC' README.md docs reference
```

출처는 [S01 등의 고정 번호](../reference/sources.md)로 찾을 수 있다. 새 자료를 추가하려면 [기여 안내](../CONTRIBUTING.md)를 참고한다.
