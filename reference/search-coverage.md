GitHub에서는 검색 결과가 없어도 저장소의 파일을 직접 읽을 수 있는 경우가 있었다. 공개 이슈도 살펴보고, 이 저장소의 [난방 정정 PR #1](https://github.com/mahlernim/baha-wallpad-packets/pull/1)을 구현 코드와 비교했다. 검색 결과 수가 공개 자료의 전체 수를 뜻하지는 않는다.

초기 구현 비교는 `f9dfed0`을 기준으로 했으며 [S30](sources.md#s30)에 남겨 두었다. 이후 외출 온도 디코더와 외출 해제 쓰기를 수정한 v0.1.1은 [S35](sources.md#s35)로 구분한다. 이는 공개 코드의 변경 이력이며 실제 장비의 업데이트 여부는 확인하지 않았다.

## 접근 제한과 후속 검색 단서

| 자료 | 확인한 내용 | 접근 상태와 참고 사항 |
| --- | --- | --- |
| [iF BaHa-Cube Series 2](sources.md#s01) | 검색 색인의 제품 설명을 다른 1차 자료와 함께 확인 | 일부 직접 조회에서 403 오류 발생 |
| [nanro 설명서 색인](sources.md#s13) | MC200·DT100·DT200 개정명과 색인상 게시일 | 직접 조회 시 403 오류. 첨부 본문은 미확인 |
| [Naver 카페 SDS 분석 글](https://cafe.naver.com/stsmarthome/7256) | [485-connector](sources.md#s33)의 인용 링크 | 본문을 열람하지 못해 BAHA의 근거로 사용하지 않음 |
| 옛 `samsungbaha.co.kr`, `yppdt.com` | 과거 제품 기록·기업 발표에 나온 도메인 | 조사 도구로 홈페이지를 열지 못함. 도메인 만료나 서비스 종료 여부는 알 수 없음 |
| 다른 모델의 인증번호·관보 사본 | 검색에서 발견한 후속 단서 | 원 규제기관에서 정확한 모델의 자료를 확보해야 함 |

산업용 MC200, 다른 지역의 DT200 Modbus 장치, Samsung HVAC, SDS·EZON 자료는 이름이 비슷해도 BAHA와 별도로 다뤘다. 수리 사례는 모델 식별에만 참고했으며, 고장 빈도나 일반 수리법으로 확대하지 않았다.

## 조사 범위와 갱신 방법

이번 조사는 검색엔진에 노출되는 공개 자료를 중심으로 했다. 로그인 전용 카페, 삭제된 첨부, 모든 웹 아카이브, 비공개 설치 설명서까지 다루지는 못했다. 자료를 찾지 못했다는 기록은 그 자료가 존재하지 않는다는 뜻이 아니다.

새 자료는 날짜, 모델 접미사, 원저자, 접근 상태를 확인해 [출처 목록](sources.md)에 추가한다. 기술적 내용은 본문이나 캡처로 검증하고, 검색 미리보기만 확인한 자료에는 그 한계를 표시한다. 다른 문서가 인용한 자료도 가능한 한 원문을 찾아 중복 인용을 구분한다.
