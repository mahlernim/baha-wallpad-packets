# 현관 / 일괄소등 노드 `1F 0F`

상위 문서: [README](../README.md)  
바로 가기: [프로토콜 개요](protocol-overview.md) | [하드웨어](hardware.md) | [거실 조명 `10 04`](lighting-node-10-04.md) | [난방 `40 90`](heater-node-40-90.md) | [참고 자료](../reference/README.md)

`1F 0F`는 현관 일괄소등 스위치 분기선을 연결했을 때 관찰된 노드다. 이 설치에서는 `09`를 OFF, `0A`를 ON으로 사용할 수 있었다. 노드가 스위치 자체인지 중계 컨트롤러인지는 아직 확인하지 못했다.

## 조회 / 상태 응답

폴링 요청:

```text
02 1F 0F 01 00 13 00
```

응답 형식:

```text
02 1F 0F 81 01 <value> <chk> 00
```

안정 상태에서 관찰된 예:

```text
02 1F 0F 01 00 13 00 -> 02 1F 0F 81 01 0A 98 00
```

## 쓰기 형식

실측한 쓰기 형식:

```text
02 1F 0F 02 01 <value> <xor_checksum> 00
```

| 시험 결과 | 값 |
| --- | --- |
| 수용됨 | `08`, `09`, `0A` |
| 거부됨 | `00`, `0B`, `0E` |

## 상태 값과 제어 시 주의점

| 값 | 관찰된 의미 | 제어에 사용할 때 |
| --- | --- | --- |
| `09` | OFF | OFF 값으로 사용 |
| `0A` | ON | ON 값으로 사용 |
| `08` | 일시 상태 / 비고정 상태 | 일반 ON / OFF 버튼 값으로 사용하지 않음 |

`08` 쓰기에서 관찰한 동작:

- 명령을 수용하고 즉시 `08`로 응답했다.
- 기존의 안정 상태가 ON이면 다음 조회에서 `0A`로 돌아왔다.
- 거실 조명 마스크는 즉시 바뀌지 않았다.

## 아직 확인하지 못한 구조

- `1F 0F`가 물리 현관 스위치, 상위 컨트롤러, 상태 중계 노드 중 어느 것인지
- 물리 버튼이 `1F 0F` 쓰기를 직접 발생시키는지, 다른 컨트롤러를 거쳐 상태가 반영되는지

이 구조는 미확인이지만, 위에 기록한 상태 값과 쓰기 동작은 해당 설치에서 확인했다.
