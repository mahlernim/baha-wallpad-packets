# 아직 확인하지 못한 사항

[지식 지도](knowledge-map.md) | [출처 목록](../reference/sources.md) | [검색 범위](../reference/search-coverage.md)

2026-09-05까지의 공개 자료와 실측에서 남은 질문들이다. 새 설명서나 식별 가능한 캡처가 나오면 이 목록과 관련 문서를 함께 갱신한다.

| 주제 | 현재 알 수 있는 것 | 추가로 필요한 근거 |
| --- | --- | --- |
| 정확한 `BHWP-2711C/A` 설명서 | 제품 라벨 / PCB와 기초 모델의 디자인 기록 | 접미사까지 일치하는 제조사 설명서, 공식 인증 원문, 서비스 핀맵 |
| 펌웨어와 OS | PCB 날짜와 제품 식별 표기 | 제조사 자료 또는 정확한 버전 정보 |
| `30 80`, `31 80` | 길이·XOR가 맞는 반복 조회 프레임 | 대상 장치를 식별할 수 있는 응답·상태 변화 캡처 |
| `10 06` 응답 | 외부 작성자의 6채널 쓰기 명령 | 정확한 모델 / 펌웨어와 `81` 상태 응답, capability 값 캡처 |
| `10 xx` 일반화 | `10 04`와 `10 06`의 쓰기 문법 일치 | 다른 채널 수 모델의 기록과 `node_lo`의 공식 정의 |
| `1F 0F` 내부 역할 | `09` / `0A` 안정 상태와 `08` 일시 응답 | 실제 제어기 / 중계기 구성과 버튼 입력에 따른 이벤트 연결 |
| 난방 방 수·순서 | 시험 환경의 5슬롯 테이블 | 다른 모델의 `DL`, 타입과 슬롯 매핑 |
| 난방 상위 상태 / 미지 값 | 확인된 정상·외출 값과 `02` / `03` 타입 | 비활성 / 오류 슬롯 표현, 비정상 값의 취급, 해당 모델 공식 정의 |
| 외출 쓰기 범위 | `C0`, `80`, 일반 설정온도, 단일 방 `CA`의 실측 | 다른 외출 온도값의 수락 여부를 보여주는 근거 |
| 전기적 구간 / 버스 타이밍 | 현재 프레임 구조와 `9600 8N1`, 관련 제품의 PLC / RS485 구분 | 정확한 트랜시버, 핀 순서, 종단, 방향 제어, 응답 시간, 재시도 / 충돌 규격 |
| 환기·가스·커튼·승강기·인터폰 | 과거 제품 소개에 기능 언급 | 해당 BAHA 모델의 공식 프로토콜 또는 식별 가능한 공개 캡처 |
| 현재 원격서비스 | 과거 웹 제어와 YPP / SKT 연동 발표 | 현행 서비스의 모델·설치별 공식 지원표 |

## 공개 구현의 수정과 남은 과제

`mahlernim/esphome-samsung-baha-rs485`의 수정 전 `f9dfed0`에서 확인한 외출 온도 디코더 문제는 [v0.1.1](https://github.com/mahlernim/esphome-samsung-baha-rs485/releases/tag/v0.1.1)에 반영했다. 숫자상 목표온도가 같아도 외출에서 일반 설정으로 바꾸는 데 필요한 쓰기를 유지한다. [버전별 비교](esphome-external-component.md), [S35](../reference/sources.md#s35)

조명의 4채널 고정 지원은 남아 있으며, 실제 장비에 이 릴리스가 적용되었는지는 별도 확인이 필요하다. 코드 수정과 다른 모델·설치에서의 독립 재현도 구분한다.

새 근거를 추가할 때는 어떤 모델과 조건에서 결론이 달라지는지 [기여 안내](../CONTRIBUTING.md)에 따라 적는다.
